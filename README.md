# Task Manager

A single-file HTML/CSS/JavaScript web app for managing a task list with complete, pending, and overdue tracking.

## What it does

- Lets you add and manage tasks in a list.
- Tracks tasks as complete, pending, or overdue.
- Shows the status of each task at a glance.

## How to run it

- Open `index.html` in a web browser, or
- Serve this repository with GitHub Pages, where `index.html` is the entry page.

No build step or installation is required.
